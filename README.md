# Portfolio

Personal portfolio of Andualem Mamo. Plain HTML and CSS, no build step.

- `index.html` — home: bio, projects, work, education
- `rooftop/`, `tradica/` — project pages
- `images/` — screenshots (WebP)

## Run locally

```sh
npx serve .
```

## Deploy

Netlify: connect the GitHub repo, leave the build command empty, publish directory `.` (already set in `netlify.toml`).
